# Mark Hawkings


I solve production problems: failing logins and SSO, integrations that
misbehave, systems that need understanding quickly under pressure. My
background is enterprise infrastructure across financial services,
broadcasting and the public sector. My current work is identity and access
management (SAML, OIDC, MFA, RADIUS, LDAP).

Alongside support I've delivered project work. At BBC News I rolled out the
OpenMedia newsroom platform to over 50 sites worldwide, and my PowerShell
automation cut each site's build from a month to six hours. Through
Computacenter I worked on migrations and upgrades for clients in finance,
insurance and the public sector.

I build tools to reproduce problems, automate the repetitive parts of
support, and put AI to practical use. I build with AI-assisted tooling
(Claude Code) and experiment with local LLMs.

**Featured:**
- [hemisphere](https://github.com/MarkHawk/hemisphere): drives a Gakken
  WorldEye spherical display from a Raspberry Pi 3 or a Windows PC, with
  a calibrated lens model and a framework for new visuals
- [identity-lab](https://github.com/MarkHawk/identity-lab): a Docker
  identity lab that reproduces common SSO failures on demand, with a
  support runbook for each one
- [psirt-watch](https://github.com/MarkHawk/psirt-watch): a dashboard
  that tracks Cisco security advisories through the public openVuln API
